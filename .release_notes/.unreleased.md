## Breaking Changes

## New Features

- Added Python 3.14 support. The `zarr` extra resolves to nothing on Python 3.14, so `msc.zarr` and `msc.xarray` are unavailable there: Zarr 2.x can't run on Python 3.14 (it requires `numcodecs<0.16`, which has no Python 3.14 wheels), and MSC's Zarr integration doesn't support Zarr 3.x yet. Use Python 3.13 or older for Zarr workloads, or reach MSC through the fsspec integration (`msc://` URLs) with a separately installed Zarr 3.x.
- Accessing an optional contrib module without its dependencies now raises an actionable error naming the extra to install (e.g. `pip install 'multi-storage-client[torch]'`) instead of a bare `ModuleNotFoundError`. `msc.zarr` and `msc.xarray` additionally explain when Zarr is unavailable on Python 3.14, or when an unsupported Zarr 3.x is installed.

## Bug Fixes

- Declare the record method explicitly on the cross-process `Counter`/`Gauge` telemetry proxies (derived from each instrument class's public methods). Proxy generation no longer depends on the installed OpenTelemetry's instrument shape, fixing `AttributeError: 'AutoProxy[opentelemetry.metrics.Counter]' object has no attribute 'add'` under OpenTelemetry version skew.
