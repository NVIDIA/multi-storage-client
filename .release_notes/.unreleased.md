## Breaking Changes

## New Features

- Rust S3 profiles can stream binary writes with `rust_client.streaming_write`: parts upload while the file is written, with memory bounded by the part size and in-flight part count instead of the object size.

## Bug Fixes

- Fix POSIX file listings that skipped files after a pagination cursor inside or just before a directory's file keys.

- Reduce default local sync thread concurrency for Python storage providers to account for parallel file transfers within each batch.
- Fix Rust buffer compatibility in fsspec reads, Path operations, manifest loading, and Explorer previews while preserving underlying storage buffers.
- Write resumable Rust downloads directly into one staging file, avoiding the final merge and reducing disk I/O and temporary space. Partial downloads saved in the previous state format restart once after upgrading.
- Invalidate download checkpoints before final sync and keep range writes on one validated file handle, preventing unsafe reuse after writeback failures and rejecting unsafe staging directories.
