## Breaking Changes

## New Features

- Local sync progress bars now display the combined receive/send network rate of the MSC process and its sync workers on macOS and Linux, including while a large file is still transferring. Traffic from unrelated processes is excluded; the rate measures process network activity rather than bytes successfully synchronized.
- `StorageClient.download_file` accepts optional `metadata` from `info` to avoid a repeated provider lookup.

## Bug Fixes

- GCS multipart `StringIO` transfers use UTF-8 consistently, including on systems with non-UTF-8 locales.
- Range reads now reuse complete cached files without requiring an ETag when source version checking is disabled, avoiding unnecessary chunk downloads and assembly.
- Immutable configuration dictionaries reject in-place union updates with `|=`.
- Pending manifest overwrites return the new metadata when `include_pending=True`.
- Cancelling a local ``msc sync`` with Ctrl+C now stops worker processes and network sampling, removes temporary files staged by stopped worker processes, and exits promptly with status 130 instead of waiting for in-flight transfer thread pools.
- Explorer previews pass the supported byte-range type, avoiding an unnecessary full-file fallback for range-capable clients.
- `Path.write_text()` now honors its `errors` argument when encoding text.
- `open(..., "rb", prefetch_file=False)` now fetches only the requested byte ranges when caching is disabled, instead of downloading the entire object into memory.
- Range reads on profiles with replicas and no cache now return only the requested bytes, reading from replicas in priority order before the source, instead of returning the entire object.
- Files opened with `disable_read_cache=True` no longer read from or populate the cache when they use range reads.
- Opening an object for a full download now reuses its initial metadata lookup, avoiding an extra storage request for direct reads.
- Cached reads skip unnecessary access-time updates with FIFO, RANDOM, and NO_EVICTION policies, reducing filesystem overhead while preserving LRU and MRU tracking.
