## Breaking Changes

## New Features

- Buffer small uncached binary range reads and seeks with an 8 MiB block. Configure the size or disable buffering with `MSC_REMOTE_READ_BUFFER_SIZE`.
- `open(path, "wb", writer_options=StreamingWriterOptions(...))` streams a binary write through a bounded multipart upload on S3-compatible profiles with the Rust client: parts upload while the file is written, with memory bounded by the part size and in-flight part count instead of the object size. `MultiStorageFileSystemWriter` and `msc.torch.save` accept `writer_options` too.

## Bug Fixes

- Honor `prefetch_file=False` for binary opens on clients without a cache or replicas so reads can fetch byte ranges on demand regardless of `memory_load_limit`.
- Include hidden files and files inside hidden directories in recursive deletion, including checkpoint files named `.metadata`.
- Fix POSIX file listings that skipped files after a pagination cursor inside or just before a directory's file keys.
- Reduce default local sync thread concurrency for Python storage providers to account for parallel file transfers within each batch.
- Fix Rust buffer compatibility in fsspec reads, Path operations, manifest loading, and Explorer previews while preserving underlying storage buffers.
- Write resumable Rust downloads directly into one staging file, avoiding the final merge and reducing disk I/O and temporary space. Partial downloads saved in the previous state format restart once after upgrading.
- Invalidate download checkpoints before final sync and keep range writes on one validated file handle, preventing unsafe reuse after writeback failures and rejecting unsafe staging directories.
