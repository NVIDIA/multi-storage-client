## Bug Fixes
- `download_file` now hands the resolved symlink target's metadata to the provider (instead of the zero-length symlink marker's), so large targets use multipart downloads and READ metrics report the real size; it also no longer issues two HEAD requests when no metadata is supplied.
- `open(path, "r", encoding=...)` with caching enabled now honors the requested mode and encoding when the object is served from the cache; the cache-first fast path previously opened the cached file in binary mode (so `read()` returned `bytes`), and cached text opens ignored a non-default `encoding`.
