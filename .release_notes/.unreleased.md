## Bug Fixes

- Reduce memory usage for S3 profiles using Rust by initializing boto3 lazily and using Rust for object metadata and directory checks.
- Sync now raises a `SyncError` as soon as a worker process exits unexpectedly, instead of returning a result that omits that process's work or hanging on a queue lock the process held.
- Manifest registration and conversions preserve symlink targets and storage classes.
- GCS listings retain in-range directories when an object exceeds `end_at`, including directory prefixes returned on later pages.
- Relative POSIX paths are made absolute without resolving symlinks, so `msc.delete`, `msc.make_symlink` and `msc.Path` act on a symlink named by a relative path instead of on the file it points to.
