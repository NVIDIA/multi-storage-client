## Breaking Changes

- Drop Python 3.10 support.

## New Features

- `StorageClient.read` accepts a `SuffixRange` to read the last bytes of an object. The fsspec filesystem (`msc://` URLs) uses it for `cat_file` with a negative `start` and no `end`, so reading the end of an object takes a single request instead of a metadata request plus a ranged read on POSIX, S3-compatible, GCS, and AIStore providers.

## Bug Fixes

- Telemetry child startup now times out after 60 seconds and cleans up failed children, allowing storage operations to continue without metrics.
- Cloud listings translate provider errors raised while fetching the first or later pages, including Rust recursive S3 listings.
- Single-file listings honor attribute filters for storage and metadata providers.
