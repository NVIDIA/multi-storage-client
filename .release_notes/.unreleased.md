## New Features

- The native Rust client supports read-only JSONL manifest snapshots on S3 and POSIX, and applications can select their own async metadata providers through profile YAML.
- With a logical metadata provider, the native Rust client's `is_empty` checks an exact logical key or descendants of the named directory. With a physical storage profile, prefix matching follows the storage backend.
