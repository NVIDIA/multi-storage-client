## Breaking Changes

## New Features

- `StorageClient.info()` defaults to the root directory, whose `metadata` field describes each storage location behind the profile, keyed by storage backend name: the provider type and the options that identify the location. Profiles with several storage backends report every backend. The HuggingFace provider also reports `properties`: the commit the configured revision currently points to and the licenses from the repository card. Pass `include_root_properties=False` to skip that lookup.

## Bug Fixes

- Sync now raises a `SyncError` as soon as a worker process exits unexpectedly, instead of returning a result that omits that process's work or hanging on a queue lock the process held.
